# An Enrollment is free or has a fixed fee, Packages are optional offers, and Orders stay behind the Enrollment

The three championships planned for the next season share one shape. Kartsport enrollment is free, with a discounted Promotional Package covering the renewal, a BIB and the first race. Fourstroke enrollment is free, with payment handled outside the platform. BKQ has a fee that includes the licence renewal. We decided the following:

- An Enrollment is either free or costs a fixed Enrollment Fee, the same whatever the Licence. Fee ranges set by the organizer per Order are not allowed.
- The fee can cover the Licence Request renewing the Driver's Licence for the championship's year, the same way a Package covers it. A Driver who already holds a valid Licence pays the same fee.
- A Promotional Package including an Enrollment replaces the fee rather than adding to it.
- The fee, and Packages including an Enrollment, are bought only while enrolling, never on their own.

The Order remains the record of what is owed and paid. Drivers see it only as the Enrollment's payment, on the Enrollment's page, so a driver never moves between enrollment and order pages.

## Considered Options

- Only Packages: a championship with a fee defines a required Package. Rejected: organizers describe it as "the enrollment costs X", and a required Package for every paid championship hides that.
- Putting the licence renewal as a line on the enrollment's Order, so renewing and enrolling is always one payment. Rejected: the renewal's amount is set during review, so every Enrollment would wait for that review. It would also reverse ADR 0004.
