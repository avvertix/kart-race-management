# Issue promo codes

Use promo codes for discounts on race fees, e.g. prizes for last season's results or a promotion. They work in championships with Entitlements turned on.

1. **Create a code** for the target championship. It can be a current one or a future one.
2. **Choose what it gives:**
   - a number of race fees (credits), or
   - an amount of money to spend on race fees (balance).
3. **Send the code's link to the winner or customer.** The link shows the code, a QR code and how many times it has been used.

## What happens next

- The person claims the code for one Licence in their account. From then on it is applied automatically when that Licence registers for a race in the championship.
- Without an account, the person types the code into the race registration form. It is claimed for the licence number entered.
- Once claimed, nobody else can claim the code.

To exclude a race, e.g. a special event, turn Entitlements off in that race's settings.

Promo codes discount the race fee only, not tyres, and one per race registration. To discount licences or enrollments, use Prices or Promotional Packages instead.
