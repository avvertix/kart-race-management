# Race number ranges

| Range | Name | Use |
|---|---|---|
| 1–999 | Championship BIB | Can be reserved for a Driver for the whole championship |
| 1000–5000 | Race-only BIB | Participants of special categories who take part in one or two races; cannot be reserved |

## Rules

- A race number is unique within a race.
- Unless the championship allows different race numbers, a Driver uses the same number in every race of the championship, and nobody else can use it.
- A reserved number can only be used by the Driver it is reserved for.

## What the race number picker shows

| State | Meaning |
|---|---|
| Free | Can be picked |
| Reserved | Has a pending or confirmed reservation |
| Already used | Raced in this championship by another Driver |

The public picker shows only the state. Organizers also see who holds each number.
