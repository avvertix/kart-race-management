# Confirm enrollments and race numbers

Race numbers are first confirmed, first served. Confirm enrollments in the order they were submitted.

1. **Open the championship's enrollments** and filter by *submitted*.
2. **For each enrollment, check:**
   - the Licence is valid for the championship year. If it is still being requested or renewed, wait;
   - the Competitor is named, if the Driver is underage;
   - the payment is confirmed, if enrollment is paid.
3. **Confirm the enrollment.** The race number the Driver picked is confirmed with it. The Driver's registrations for races without results are re-evaluated for points eligibility.
4. **Otherwise, reject it** with a reason, which releases the race number.

## Release or change a race number

A pending number stays held until you confirm or release it. To give the number to someone else, release it first. After confirmation, only an organizer can change a Driver's number.

## Recalculate wildcards for a past race

Confirming an enrollment doesn't change races that already have results. To update one, open the race and run *recalculate wildcards*, then reassign points if needed.
