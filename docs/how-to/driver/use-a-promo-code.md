# Use a promo code

A promo code reduces your race fees in one championship.

## With an account

1. Open the code's link, or enter the code on your dashboard.
2. Choose the licence it is for. Once claimed, the code belongs to that licence and nobody else can claim it.
3. Register for races with that licence. The discount is applied automatically.

The link also shows how many times the code has been used.

## Without an account

Type the code into the race registration form. It is claimed for the licence number you enter, so always use the same licence number. If you later add that licence to an account, the code moves with it.

## Good to know

- A promo code covers the race fee, not tyres.
- One promo code is used per race registration.
- Some races may not accept promo codes. The race page says so.
