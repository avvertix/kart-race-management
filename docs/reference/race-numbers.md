# Race number ranges

| Range | Name | Use |
|---|---|---|
| 1–999 | Championship BIB | Can be reserved for a Driver for the whole championship |
| 1000–5000 | Race-only BIB | Participants of special categories who take part in one or two races; cannot be reserved |

## Rules

- A race number is unique within a race.
- Unless the championship allows different race numbers, a Driver uses the same number in every race of the championship, and nobody else can use it.
- A reserved number can only be used by the Driver it is reserved for.

## What the race number picker shows

| State | Meaning |
|---|---|
| Free | Can be picked |
| Reserved | Has a pending or confirmed reservation |
| Already used | Raced in this championship by another Driver |

The public picker shows only the state. Organizers also see who holds each number.

A User who claimed or added Participants in past championships also sees **Numbers you used before**: each number with its championship and driver, quick to pick when free. It is only a suggestion; numbers are still first confirmed, first served.

## Previous numbers, for organizers

- On each Enrollment, the organizer can look up the numbers the Driver used in past championships, matched by licence number, by name and birth date, or by the User who registered them, and confirm or change the picked number.
- ACI championships can copy reservations from a past championship, matched by licence number, before enrollment opens. A Driver who enrolls with that licence number finds the number already reserved. ASI championships can't, because ASI licence numbers change every year.
