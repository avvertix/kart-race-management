# Process a licence request

> The steps of the current organizer process are still being collected. This guide uses the generic sections of a request.

You are notified of each new request and each resubmission after a change request. The applicant is notified when the request is received, when you ask for changes and when the licence is emitted. See [Notifications](../../reference/notifications.md).

1. **Open the submitted request.** It shows the Licence Type, the holder's details, the parents' details (underage holders only), the uploaded documents, the signed forms and the payment proof.
2. **Set the price**, if the Product is priced as a range. The amount starts from the Price locked when the order was placed; an amount outside the range needs a reason. The applicant is notified to pay.
3. **Check the payment proof** and confirm the payment.
4. **Check each section and document.** If something is wrong, e.g. an unreadable identity card or an expired medical certificate, flag that section or document with a note and ask for changes. The applicant is notified, fixes only the flagged parts, and submits again.
5. **Download the request as a single PDF**, with all forms and uploaded documents, and send it to the Licence Provider. Mark the request as forwarded.
6. **When the provider replies:**
   - upload the temporary licence PDF, enter the licence number and set the validity year (pre-filled: requests from December onwards default to the next year), then mark the request as emitted. The Licence appears in the applicant's account, ready to download and use for enrollment;
   - or reject the request with a reason.

## Keeping documents

Uploaded documents are kept until 12 months after the licence expires, then deleted. The temporary licence PDF is kept as long as the Licence.
