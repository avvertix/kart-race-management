# Process a licence request

> The steps of the current organizer process are still being collected. This guide uses the generic sections of a request.

You are notified of each new request and each resubmission after a change request. The applicant is notified when the request is received, when you ask for changes and when the licence is emitted. See [Notifications](../../reference/notifications.md).

Every request is a renewal: it carries last year's licence number. First licences are arranged with you outside the platform.

1. **Open the submitted request.** It shows the Licence Type, whether the competitor licence is included, last year's licence number, the holder's details, the parents' details (underage holders only), the uploaded documents, the signed forms and the payment.
2. **Set the amount** to pay for the Licence Type requested. The applicant is notified to pay. A request covered by a Promotional Package needs no amount.
3. **Check the payment proof** and confirm the payment.
4. **Check each section and document.** The documents are the same for every Licence Type: check they fit the one requested, e.g. the right medical certificate. If something is wrong, e.g. an unreadable identity card or an expired medical certificate, flag that section or document with a note and ask for changes. The applicant is notified, fixes only the flagged parts, and submits again.
5. **Download each document** and send them to the Licence Provider. Mark the request as forwarded.
6. **When the provider replies:**
   - upload the temporary licence PDF, check the licence number (pre-filled with last year's for ACI, which keeps it across years; ASI assigns a new one) and set the validity year (pre-filled: requests from December onwards default to the next year), then mark the request as emitted. The Licence appears in the applicant's account, ready to download and use for enrollment;
   - or reject the request with a reason.

## Keeping documents

Uploaded documents are kept until 12 months after the licence expires, then deleted. The temporary licence PDF is kept as long as the Licence.
