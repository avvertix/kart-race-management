# Notifications

Only the notifications added for licence requests are listed here. Race registration notifications don't change.

| When | Who is notified |
|---|---|
| A Licence Request is submitted | The applicant (request received) and the organizer |
| An applicant submits again after a change request | The organizer |
| The organizer asks for new documents or changes | The applicant |
| The Licence is emitted | The applicant |

Enrollments, orders and promo codes send no notifications for now.
